Generate standup notes.

1. Check git log for recent commits by the current user
2. Check current branch and uncommitted changes
3. Check open PRs if possible
4. Format as Yesterday / Today / Blockers

Use the standup-notes skill patterns.
Keep it concise — each bullet should be one line.
