# Delivery Process

Step-by-step workflow to produce a marketing report + asset package for a new client.

## Phase 1 — Intake (Day 1)

- [ ] Client kickoff call (30 min): goals, target customer, budget, timeline
- [ ] Collect: website, social handles, Google Business Profile URL, existing brand assets, current pricing
- [ ] Create `clients/<client-slug>/` folder
- [ ] Copy `TEMPLATE.md` → `clients/<client-slug>/report.md`

## Phase 2 — Research (Days 2–4)

Save raw findings in `clients/<client-slug>/research-notes.md`.

- [ ] **Business audit:** website, GBP, social profiles, review sentiment
- [ ] **Market data:** industry reports, CAGR, demand trends, search volume (Google Trends)
- [ ] **Competitors:** pull 5–8 nearest competitors; record rating, review count, price range, content cadence, strengths, gaps
- [ ] **Keyword research:** local + service keywords, seasonal spikes
- [ ] **Brand voice extraction:** analyze client's existing copy and reviews

## Phase 3 — Strategy (Days 5–6)

- [ ] Identify top 3 growth levers
- [ ] Define brand voice profile
- [ ] Draft 4–5 content pillars
- [ ] Build 30-day content calendar
- [ ] Scope 2–3 campaigns with budgets

## Phase 4 — Assets (Days 7–10)

- [ ] Adapt `../social-media-graphics/` templates to client brand
- [ ] Export finals as PNG/JPG to `clients/<client-slug>/assets/`
- [ ] Build Google Business Profile cover + service photos
- [ ] Write 30 caption drafts matching the calendar

## Phase 5 — Delivery (Days 11–12)

- [ ] Final report review pass (remove all placeholders, verify every stat has a source)
- [ ] Export report to PDF
- [ ] Package assets in a zip
- [ ] Deliver via Notion / Google Drive / email
- [ ] Schedule 30-day follow-up call

## Quality bar

- Every claim has a citation
- Every recommendation has a specific metric
- No generic advice ("post more") — every action is specific to this client
- Report should read as if it could only have been written for this one business
